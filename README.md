# SnapStack

> Convert Instagram carousel posts into beautiful PDFs while also supporting media downloads.

## Overview

SnapStack is a web application designed to help users organize Instagram content by converting carousel posts into high-quality PDF documents. The project also supports downloading reels, images, and future multi-platform expansion.

## Features

- Carousel → PDF
- Image Download
- Reel Download
- Responsive UI
- Extensible provider architecture
