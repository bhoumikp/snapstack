# Feature 001 - Project Setup

## Status

Planned

## Goal

Setup the project with vite to initialize the project structure for both slient and server.

## Why?

Every project requires a base without it we cant build anything.

## Scope

- Use vite to initialize
- Install required packages
- Create basic required folder structure

## Out of Scope

- Creating all files beforehand

## Success Criteria

- The project is initialized by vite
- All packages are installed
- package.json and tailwind is configured properly
